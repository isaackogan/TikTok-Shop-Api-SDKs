The TikTok Shop API SDKs are typed clients for the TikTok Shop Partner API in eight languages. Every SDK is generated from one [OpenAPI 3.1 spec](/openapi/), which is itself generated from TikTok Shop's partner documentation, so the eight cover the same 318 operations and 44 webhooks with the same names and behavior.

The generator can't write some parts, so each SDK adds them by hand:
- request signing and shop cipher handling;
- an OAuth helper for the authorization URL, token exchange and refresh;
- webhook verification with typed events;
- a single error type.

This is an unofficial project, not affiliated with or endorsed by TikTok or ByteDance. Request signing follows TikTok's documentation and has not been verified against the live API yet. If TikTok rejects a signature, please open an issue at https://github.com/isaackogan/TikTok-Shop-Api-SDKs/issues.

## Prerequisites

- **A TikTok Shop app.** Register it in TikTok Shop Partner Center. It gives you an **app key** and an **app secret**. Seller and partner apps also have a **service ID**, which authorization URLs need. Keep the app secret on your server.
- **A redirect URL** registered on the app. TikTok sends the seller back there with an authorization `code`.
- **A supported runtime:** Node.js 22, Python 3.11, Go 1.22, Java 11, PHP 8.2, Rust 1.88 or .NET 8, or newer.

The [concepts](/getting-started/concepts/) page explains each credential and how they fit together.

## Authorize a shop

A seller authorizes your app in three steps:
1. You send them to an authorization URL.
2. TikTok redirects them back with a `code`.
3. You trade that code for an access token and a refresh token.

The access token expires, so refresh it before it does. Each SDK's OAuth helper builds the URL and calls the token endpoints.

<Tabs syncKey="sdk">
  <TabItem label="TypeScript">
    ```ts
    import { TikTokShopAuth } from 'tiktok-shop-api';

    const auth = new TikTokShopAuth({
      appKey: process.env.TTS_APP_KEY!,
      appSecret: process.env.TTS_APP_SECRET!,
      serviceId: process.env.TTS_SERVICE_ID!, // seller and partner flows
    });

    // 1. Send the seller here. `type` is 'seller' | 'partner' | 'creator'; `region` is 'us' | 'row'.
    const url = auth.authorizationUrl({ type: 'seller', region: 'us', state: 'csrf-token' });

    // 2. TikTok redirects back with ?code=...; exchange it.
    const code = new URL(callbackUrl).searchParams.get('code')!;
    const tokens = await auth.exchangeCode(code);
    // tokens.accessToken, tokens.refreshToken, tokens.openId, tokens.grantedScopes, ...

    // 3. Before the access token expires (accessTokenExpireIn is a Unix timestamp):
    const renewed = await auth.refresh(tokens.refreshToken);
    ```
  </TabItem>

    ```go
    import (
    	"context"
    	"fmt"

    	tiktokshop "github.com/isaackogan/TikTok-Shop-Api-SDKs/go"
    )

    func authorize(ctx context.Context) error {
    	auth := tiktokshop.NewAuth(tiktokshop.AuthOptions{
    		AppKey:    "APP_KEY",
    		AppSecret: "APP_SECRET",
    		ServiceID: "SERVICE_ID",
    	})

    	url, err := auth.AuthorizationURL(tiktokshop.AuthorizationURLOptions{
    		Type:   tiktokshop.AuthSeller,
    		Region: tiktokshop.RegionUS,
    		State:  "my-csrf-token",
    	})
    	if err != nil {
    		return err
    	}
    	fmt.Println("send the seller to", url)

    	tokens, err := auth.ExchangeCode(ctx, "CODE_FROM_THE_REDIRECT")
    	if err != nil {
    		return err
    	}
    	fmt.Println(tokens.AccessToken, tokens.OpenID, tokens.GrantedScopes)

    	tokens, err = auth.Refresh(ctx, tokens.RefreshToken)
    	if err != nil {
    		return err
    	}
    	fmt.Println("expires at", tokens.AccessTokenExpireIn)
    	return nil
    }
    ```

## Make your first call

Most operations act on one shop, identified by its **shop cipher**. Find it with the authorized-shops call, then give it to the client. The client:
- signs each request;
- adds `app_key` and `timestamp`;
- sends your access token in the `x-tts-access-token` header;
- adds `shop_cipher` to the operations that need it.

<Tabs syncKey="sdk">
  <TabItem label="TypeScript">
    ```ts
    import { TikTokShop } from 'tiktok-shop-api';

    const client = new TikTokShop({
      appKey: process.env.TTS_APP_KEY!,
      appSecret: process.env.TTS_APP_SECRET!,
      accessToken: tokens.accessToken,
    });

    // Find the shop cipher
    const shops = await client.authorization.getAuthorizedShops();
    const shopCipher = shops.data?.shops?.[0]?.cipher;

    const seller = client.withShop({ accessToken: tokens.accessToken, shopCipher });
    const orders = await seller.orders.getOrderList({ pageSize: 20 });
    ```
  </TabItem>
  <TabItem label="Python">
    ```python
    import os

    from tiktok_shop_api import TikTokShop

    access_token = os.environ["TTS_ACCESS_TOKEN"]

    with TikTokShop(os.environ["TTS_APP_KEY"], os.environ["TTS_APP_SECRET"], access_token=access_token) as client:
        # Find the shop cipher
        shops = client.authorization.get_authorized_shops()
        assert shops is not None
        shop_cipher = shops.to_dict()["data"]["shops"][0]["cipher"]

        seller = client.with_shop(access_token=access_token, shop_cipher=shop_cipher)
        orders = seller.orders.get_order_list(page_size=20)
    ```

Every SDK groups its operations by API area, with the same names as the spec's tags: orders, products, fulfillment, logistics, finance, the three affiliate areas, and so on. A failed call raises the SDK's error type, carrying TikTok's `code`, `message` and `request_id`; see [errors](/getting-started/errors/).
